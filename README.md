# 🏛️ Enrichissement Territorial Pyramidal (Corse)

1. **Installer les dépendances** : `pip install -r requirements.txt`
2. **Configuration (`.env`)** : Traite la base `France-Corse` depuis 4 collection source (`Corse-du-Sud`) vers 3 collections enrichies (`France_Corse_syntheses_analysis`, `France_Corse_domaines_analysis`, `France_Corsemensuel_analysis`).
3. **Lancer le pipeline** : `python main.py`
