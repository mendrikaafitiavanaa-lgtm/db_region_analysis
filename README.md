# 🏛️ Enrichissement Territorial Pyramidal (Corse)

1. **Installer les dépendances** : `pip install -r requirements.txt`
2. **Configuration (`.env`)** : Traite la base `France-Corse` depuis 1 collection source (`Corse-du-Sud`) vers 3 collections enrichies (`Corse_Sud_syntheses_anaylisis`, `Corse_Sud_domaines_anaylisis`, `Corse_Sud_mensuel_anaylisis`).
3. **Lancer le pipeline** : `python main.py`
